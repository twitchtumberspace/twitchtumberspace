# Crypto Info Dashboard

Ein einfaches Web-UI mit:

- Top 100 Coins (Preis in EUR, Auto-Update jede Minute)
- Top 10 Trending Coins
- Coin-Rechner (zeigt Preis von 1 Coin + wie viele Coins du für einen EUR-Betrag bekommst)
- Account-Erstellung (lokal gespeichert im Browser)
- Light/Dark Mode Toggle

## Starten

```bash
python3 -m http.server 8000
```

Danach im Browser öffnen: <http://localhost:8000>
